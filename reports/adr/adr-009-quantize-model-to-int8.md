# ADR-009: Квантизация модели до INT8 для инференса

**Дата:** 2025-11-10  
**Статус:** Принято  
**Контекст:** 
Модель весит ~200 MB (FP32), инференс на CPU занимает ~600 мс на 1000 окон.  
Нужно ускорить и уменьшить память без значимой потери качества. Это неприемлемо для production-среды.

**Решение:**  
- Обучать модель в FP32  
- После полного обучения применять **post-training static quantization** (`torch.quantization`)
- веса и activations → INT8  
- LayerNorm и softmax оставляем FP32    
- Сохранять квантизированную версию как `model_quant.pt`  
- Использовать её в production-инференсе

**Последствия:**  
✅ **Плюсы:**  
- Уменьшение размера модели в 4x (до ~120 МБ)  
- Ускорение инференса на CPU (в 2–3x)  
- Совместимость с `torchscript` и `ONNX`
- Нет необходимости менять код инференса, кроме загрузки quantized версии.
- Низкое потребление памяти

⚠️ **Минусы:**  
- Небольшая потеря точности (~1–2%)  
- Требуется тестирование на валидационной выборке  
- Не поддерживает все операции (например, сложные attention)
- Нельзя дообучать уже квантованную модель — требует полного fp32 чекпоинта.  
- Ограничение по платформе: x86_64 с AVX2 или ARMv8.

**Связанные файлы:**  
- `quantize.py`  
- `model_quant.pt`

**Решение принято:** AB, 2025-11-10
