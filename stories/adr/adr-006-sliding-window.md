# ADR-006: Использование sliding window для обучения и инференса

**Дата:** 2025-11-10  
**Статус:** Принято  
**Контекст:** 
Логи разной длины (от десяков до десятков тысяч токенов).  
Нужен фиксированный размер входа для Transformer.

**Решение:** 
Разбивать последовательность `event_id` скользящим окном:
- длина окна `L = 512`;  
- шаг 1;  
- цель = следующий токен `event_seq[i+L]`;  
- короткие логи дополняются до 512 pad-токеном `0` (``).

**Последствия:**  
✅ **Плюсы:** 
- Унифицированный тензор `(B, 512)` для любого входа.  
- Простая интеграция с PyTorch DataLoader.

⚠️ **Минусы:** 
- Взрыв объёма данных (окна пересекаются).  
- Для длинных логов > 90 % окон содержат пересечения → дублирование на диске.  
- Последние токены лога не используются как цель (отбрасываются).

**Решение принято:** AB, 2025-11-10
