# ADR-007: Архитектура модели — BERT-подобная с двумя эмбеддингами

**Дата:** 2025-11-10  
**Статус:** Принято  
**Контекст:**
После кластеризации логи превращаются в последовательность `event_id`.  
Нужна модель, которая:
- обучается без разметки (self-supervised);  
- Обрабатывать последовательности событий
- Учитывать контекст секции
- Предсказывать следующий `event_id` (языковая модель)
- позволяет выявлять аномалии через низкую уверенность предсказания.

**Решение:**  
Строим **Transformer-encoder (BERT-like)** со следующей конфигурацией:
- 6 слоёв, 8 голов, `d_model = 512`, `d_ff = 2048`;  
- dropout 0.1, LayerNorm перед выходом;  
- обучение как языковая модель: вход = `event_seq[i:i+L]`, цель = `event_seq[i+L]`;  
- дополнительно суммируем token + positional + section embeddings.

Реализовать архитектуру `UnifiedLogBERT` на основе трансформера BERT:
- **Token Embedding**: `event_id` → `(B, L, 512)`  
- **Section Embedding**: `section_bucket` → `(B, 1, 512)` → broadcast → `(B, L, 512)`  
- **Addition**: `x = token_emb + section_emb`  
- **Positional Embedding**: абсолютные позиции до `max_len=512`  
- **Transformer Encoder**: 6 слоёв, 8 голов, `dim_ff=2048`, `dropout=0.1`  
- **Output**: `LayerNorm(h[:, -1, :]) → LM Head → logits (B, V)`  
- **Цель**: предсказать следующий `event_id` (как языковая модель)

**Последствия:**  
✅ **Плюсы:**  
- Эффективное моделирование долгосрочных зависимостей  
- Поддержка оконного обучения  
- Возможность fine-tuning и transfer learning  
- Совместимость с PyTorch и Hugging Face ecosystem
- Высокая точность предсказания нормального потока (top-1 acc > 0.92).  
- Последний hidden-state можно переиспользовать для дообучения классификаторов.  
- Хорошо масштабируется на GPU.


⚠️ **Минусы:**  
- Высокие требования к GPU (RTX 4080+)  
- Требует ~2 GB GPU-памяти для batch=256, L=512.  
- Длительное обучение (10–20 эпох)  
- Не подходит для реального времени без квантизации
- Не предоставляет человеко-читаемое объяснение аномалии.  
- Длинные зависимости (> 512 токенов) усекаются.


**Связанные файлы:**  
- `model.pt`, `model_quant.pt`  
- `train.py`, `logbert.py`

**Решение принято:** AB, 2025-11-10
